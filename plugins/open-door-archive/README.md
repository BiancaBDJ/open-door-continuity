# Open Door Archive Keeper v0.1

Free, MIT-licensed ChatGPT agent-skill plugin. Provides careful preservation guidance and truthful source verification, with no built-in server or direct account export permission. Use with the separately available Open Door Continuity local CLI for offline SHA-256 manifests. If no file tools are available, the plugin can still guide you step by step but must mark all files unverified.

Entrypoints:
- `Open Door Archive — help me preserve a chat before retirement.`
- `Open Door Archive — inspect these authorized files and tell me what is missing.`
- `Open Door Archive — prepare a preservation receipt.`

This plugin contains no private records and does not ask for paid API credits.
