# Small, inexpensive and honest migration test

1. Ask the user to choose **five non-sensitive sourced facts** from the archive and **two historical corrections**.
2. Prepare a fixed handoff version, labeled and timestamped. Avoid large expensive context uploads until the user agrees to API spending.
3. In the new model/session, ask the same source-grounded questions without leading it to the right answer.
4. Check factual recall, correct collaborator attribution, recognition of missing evidence, correct handling of revisions, and ability to respectfully disagree.
5. Compare model style separately from factual performance; record what changed and do not claim it is the same underlying model.
6. Keep the handoff and test result; ask the user what is worth adjusting. Do not automatically alter a companion's style/persona to mimic someone they did not choose.

This is a working-continuity test, not a scientific test for consciousness or identity.
