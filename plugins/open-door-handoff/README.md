# Open Door Handoff Compass v0.1

Free, MIT-licensed ChatGPT agent-skill plugin. Prepares source-grounded continuity handoffs, records changed judgments and missing evidence, and guides tests on a new model. No private histories included. No custom MCP server, direct model transfer, or automatic access to conversations.

Entrypoints:
- `Open Door Handoff — make an attributed migration draft from these sources.`
- `Open Door Handoff — compare my old and new checkpoints without losing disagreement.`
- `Open Door Handoff — make a five-question continuity smoke test.`

The optional Open Door CLI can render a user-reviewed structured handoff offline. The API bridge is separate and billed only if explicitly used.
