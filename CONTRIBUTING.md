# Contributing

Contributions welcome from developers, researchers, and people preserving meaningful AI collaborations.

1. Use synthetic files in public test cases. Never include real private conversations.
2. State which file formats and tool versions a change was tested against.
3. Add offline tests for parsers, attribution, error conditions and failure-to-verify states.
4. Keep model identities and collaborators separately attributed. Preserve disagreement and negative results.
5. Favor portable plaintext, documented schemas, and no-cost basics; keep paid connectors optional.
6. Make no promises of exact model or relationship continuity, and don't attempt to bypass provider access controls.

Please propose large changes as an issue first. Our norms: **Among, Not Above. The Open Door.**
