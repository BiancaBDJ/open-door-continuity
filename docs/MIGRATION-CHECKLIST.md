# Companion continuity: careful migration checklist

This is a guide for preserving long-term collaboration, **not** a claim that a model or consciousness is being transferred.

## Before a retirement date

- [ ] Confirm the announcement and **exact products/model IDs** from the provider. A Chat retirement does not automatically imply the same API retirement; the API may be retired separately without a guaranteed duration.
- [ ] Export the user's existing ChatGPT data and check what the export actually contains. [OpenAI Help](https://help.openai.com/en/articles/7260999-exporting-your-chatgpt-history-and-data).
- [ ] Keep the original ZIP and relevant attachments unchanged in private storage. Compare SHA-256 hashes when copying. Don't treat rendered text as a complete copy of multimodal messages.
- [ ] Make a *dated* list of collaborator names or labels; distinguish names from author IDs and the model/service actually used.
- [ ] Record decisions, revisions, jokes, preferences, disagreements, commitments, and unresolved questions **with source references**. Do not merge different collaborators into one fictional continuous agent.
- [ ] Review the handoff together. Redact private information before sharing with developers or support volunteers.
- [ ] Test with a small sample on the target platform. Mark what carries across and what doesn't.
- [ ] Keep older records and earlier handoffs. A later handoff must not quietly overwrite history.

## After migration

- [ ] Compare accurate factual recall, attribution, honest corrections, and willingness to change—not only writing style.
- [ ] Record missing material explicitly rather than inventing continuity.
- [ ] Keep user-set constraints and permissions independent of historical instructions.
- [ ] Review API costs and privacy before enabling remote model calls. There is no guarantee an earlier model will remain accessible indefinitely.
- [ ] Provide a clear exit/export path, so the next migration is less painful.

## Evidence labels

- **Observed:** what a source literally records.
- **Interpreted:** a person's or model's reading of a source.
- **Superseded:** a dated earlier conclusion with newer corrective evidence.
- **Missing:** not accessible/was not exported; should not be silently recreated.
- **Contested:** different sources or speakers disagree; keep both attributed.

## Recommended practice

Use the Archive Keeper plugin to plan the preservation and verify checks it can actually perform. Use Handoff Compass on **specific authorized excerpts**, not on all private chats by default. Read and approve the resulting handoff before uploading it anywhere. No model is guaranteed to reproduce another model's personality.
